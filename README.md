# Мій план

Демонстраційна веб-версія програми для заповнення **індивідуального плану виправлення
та ресоціалізації**.

**Продукт навчання та роботи учасників «Освітнього простору №8»**
ДУ «Житомирська установа виконання покарань №8».

👉 **[Відкрити демонстрацію](https://gregory-ivd.github.io/plan-uvp8/)**

---

## Навіщо це

Бланк плану видають порожнім. Людина, яка бачить його вперше, часто не розуміє, що саме
туди писати. Через це в графі про перепони з'являється «не має», цілі описують загальними
словами, і план виходить формальним.

А читають цей план тоді, коли вирішується питання про зміну умов тримання, помилування
або заміну довічного позбавлення волі покаранням на певний строк (ст. 82 Кримінального
кодексу України).

Програма веде людину по кроках і показує, як писати по суті.

## Що вона робить

1. Пояснює, що це за документ і на якому наказі він ґрунтується.
2. Веде через шапку документа і 13 розділів. До кожного розділу — підказка, живий приклад
   і перелік того, чого краще уникати.
3. Перевіряє типові помилки: порожні поля, «Не має» там, де перепона очевидна, цілі,
   сформульовані як процес замість результату, русизми (з заміною в один клік).
4. Показує чернетку всього тексту перед друком.
5. Віддає готовий документ: друк або збереження в PDF, а також файл для Word.

Розмітка документа повторює паперовий бланк установи.

## Про дані

Це **демонстраційна** версія. Не вводьте в неї справжні персональні дані.

Сторінка повністю статична: немає сервера, бази даних, аналітики й жодних зовнішніх
запитів. Усе, що ви набираєте, лишається у вашому браузері (`localStorage`) і зникає,
щойно ви натиснете «Почати заново» або очистите дані сайту.

## Версія для Windows

Повна версія працює без інтернету, запускається з флешки без встановлення й додатково
має редактор шаблону для адміністрації установи: там можна змінювати формулювання,
додавати й вилучати розділи без програміста.

## Нормативна основа

Наказ Міністерства юстиції України від 04.11.2013 № 2300/5 «Про організацію
соціально-виховної та психологічної роботи із засудженими» (у редакції наказу,
зареєстрованого в Мін'юсті 06.08.2021 за № 1099/36721).

Індивідуальна програма соціально-виховної роботи складається начальником відділення
соціально-психологічної служби разом із засудженим не пізніше 30 днів з дня прибуття
до установи, діє шість місяців і кожні шість місяців переглядається.

## Склад

| Файл | Призначення |
|---|---|
| `index.html` | розмітка сторінки |
| `styles.css` | оформлення, зокрема стилі друку самого бланка |
| `app.js` | логіка: кроки, перевірки, збірка документа |
| `template.json` | увесь текстовий вміст: інструкція, 13 розділів, підказки, приклади |
| `logo.png` | логотип «Освітнього простору №8» |

`template.json` — спільний для веб-версії та версії для Windows, тож зміст правиться
в одному місці.

## Локальний запуск

Сторінка читає `template.json` через `fetch`, тому просто відкрити `index.html` з диска
не вийде — потрібен веб-сервер:

```bash
python -m http.server 8765
```

Далі відкрити <http://127.0.0.1:8765/>.
